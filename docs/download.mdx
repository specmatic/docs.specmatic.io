## Specmatic Open Source

:::info[Artifact repository change]
Specmatic artifacts are now hosted in the [Specmatic releases repository](https://repo.specmatic.io/#releases). Update your Maven or Gradle repository configuration to download them.
:::

Release notes: [Specmatic OSS release notes](https://github.com/specmatic/specmatic/releases)

### Open Source CLI standalone executable

Read the [CLI Quick Start (in 5 min)](/getting_started/cli_quick_start) guide to learn more about using the standalone executable:

<Tabs groupId="install-specmatic">
  <TabItem value="docker" label="Docker">

To run the latest version:

```bash
docker run -it --rm specmatic/specmatic --help
```

For older versions, replace `VERSION` with the desired version number from the Docker Hub tags page:

```bash
docker run -it --rm specmatic/specmatic:VERSION --help
```

  </TabItem>
  <TabItem value="jar" label="JAR">

You can download the standalone JAR from:

  - <a href={`https://github.com/specmatic/specmatic/releases/download/${VERSIONS["specmatic-core-version"]}/specmatic-executable-all-${VERSIONS["specmatic-core-version"]}.jar`} className="external-link" target="_blank" rel="noopener noreferrer">
      GitHub Releases
    </a>

  - <a href={`https://repo.specmatic.io/releases/io/specmatic/specmatic-executable-all/${VERSIONS["specmatic-core-version"]}/specmatic-executable-all-${VERSIONS["specmatic-core-version"]}.jar`} className="external-link" target="_blank" rel="noopener noreferrer">
      Specmatic Repository
    </a>

To run the JAR:

```bash
java -jar specmatic.jar --help
```

  </TabItem>
  <TabItem value="linux-macos" label="Linux / macOS">

If you have Java 17 or above installed, you can install Specmatic with a shell script:

To install the latest version:

```bash
curl https://docs.specmatic.io/install-specmatic.sh | bash
```

To install a specific version, replace `VERSION` with a release number from GitHub:

```bash
curl https://docs.specmatic.io/install-specmatic.sh | bash -- --version VERSION
```

  </TabItem>
  <TabItem value="windows" label="Windows">

If you have Java 17 or above installed, you can install Specmatic using PowerShell:

To install the latest version:

```powershell
irm https://docs.specmatic.io/install-specmatic.ps1 | iex
```

To install a specific version, replace `VERSION` with a release number from GitHub:

```powershell
iex "& { $(irm 'https://docs.specmatic.io/install-specmatic.ps1') } --version VERSION"
```

  </TabItem>
  <TabItem value="npm" label="NPM">

To run the latest version:

```bash
npx specmatic
```

To run a specific version, replace `VERSION` with a version from npm:

```bash
npx specmatic@VERSION
```

  </TabItem>
  <TabItem value="python" label="Python (pip)">

To install Specmatic via `pip`:

```bash
pip install specmatic
```

To install a specific version, replace `VERSION` with a version from PyPI:

```bash
pip install specmatic==VERSION
```

  </TabItem>
</Tabs>
