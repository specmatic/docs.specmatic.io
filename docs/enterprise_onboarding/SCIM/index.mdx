# Configuring SCIM

Provider-specific SCIM integration guides for Specmatic Insights.

## Current Limitations

- Current scope is user provisioning and deprovisioning.
- SCIM role provisioning support is planned for a future release.

Review the operator notes in [SCIM Reference](/enterprise_onboarding/scim#operator-notes-enabling-scim-per-org) before rollout.  
That section documents the enablement sequence and the login behavior change when SCIM is enabled (SSO JIT is blocked for non-provisioned users).
