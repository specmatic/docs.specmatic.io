# Audit Trail

Specmatic Insights provides an audit trail for organization-level administrative and security activity. Organization admins can review recent audit activity in the product UI and manage export-related settings for their organization.

For the complete event schema and per-event `details` fields, see the [Audit Event Reference](/enterprise_onboarding/audit-event-reference).
For who can view audit data and configure audit export in Insights, see [Role Permissions](/enterprise_onboarding/role_permissions).

## What gets audited

Audit events capture important changes and access activity. A typical set of audited actions includes:

- Login success, login failure, and logout
- User creation, invitation events, and membership changes when users are added to an organization
- Membership removals when users are removed from an organization
- Membership role changes when a user's role is updated within an organization
- Password changes and password reset activity (password reset applies only to organizations that do not use SSO integration)
- Organization configuration changes, including license and audit configuration updates
- Build submissions from central repositories and service repositories
- License lifecycle actions such as issuing, refreshing, and revoking licenses
- Audit export lifecycle events such as export started, completed, or failed

See the [Audit Event Reference](/enterprise_onboarding/audit-event-reference) for exact event types and payload fields.

## Where admins can find audit information

Organization admins can view audit records in `Settings` -> `Audit Events`.

The `Audit Events` tab provides a paginated list of recent audit activity for the selected organization, including event type, actor, source IP, timestamp, and a summary of what happened.

If you need the exact field-level contract for ingestion or automation, use the [Audit Event Reference](/enterprise_onboarding/audit-event-reference).

## Configuring audit export

Organization admins can configure audit export behavior in `Settings` -> `Audit`.

The `Audit` tab allows admins to:

- Enable or disable audit exports
- Adjust the export batch size
- View the configured S3 destination used for audit exports

Audit export run status events (`AUDIT_EXPORT_STARTED`, `AUDIT_EXPORT_COMPLETED`, `AUDIT_EXPORT_FAILED`) are documented in the [Audit Event Reference](/enterprise_onboarding/audit-event-reference#audit-export-lifecycle).

## Accessing exported audit logs

Audit logs are exported to an S3 destination associated with your organization. If your team needs access to the relevant S3 bucket or prefix, contact Specmatic support so the required access can be provisioned and coordinated correctly.

For additional help with audit trail setup or access, contact [Specmatic support](https://support.specmatic.io).
