# Specmatic Insights

Specmatic Insights is a governance platform for understanding how the contracts in your organization are built, tested, consumed, and connected.

It turns Specmatic build reports into an operational view of your API ecosystem: services, specifications, operations, consumers, dependencies, and the gaps between them.

![Specmatic Insights overview](/img/enterprise_onboarding/insights-landing-overview.png)

## A Governance Tool for Your Contract Ecosystem

Insights gives engineering teams a shared view of contract-driven development across the organization. Use it to:

- establish a common inventory of specifications and operations
- map which services implement specifications and how services depend on one another
- measure operations covered by provider contract tests
- understand operations used by consumers through mocks
- see which contracts are shared between providers and consumers
- identify unused operations, unresolved usage, and consumers without provider coverage
- define organization-wide targets for contract test coverage and mock usage
- support conversations between provider and consumer teams with shared evidence

This makes contract data useful beyond individual CI pipelines. The goal is not only to report whether a build passed, but to make the state of your organization's contracts understandable and actionable.
