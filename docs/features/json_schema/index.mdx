# JSON Schema

Specmatic's JSON Schema support features:

* [anyOf Support](/features/json_schema/anyOf-support) - Support for anyOf schema composition
* [oneOf Support](/features/json_schema/oneOf-support) - Support for oneOf schema composition
* [Discriminator](/features/json_schema/discriminator) - Support for OpenAPI discriminator keyword
