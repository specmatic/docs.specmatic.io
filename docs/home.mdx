# Shift-left API Integration

## Auto-fix integration drift before integration

Specmatic turns API specifications into **executable contracts**, continuously verifying that every change made by AI coding agents and engineers stays true to the desired behaviour.

**Ship AI-ready APIs 10x faster, from intent to implementation, with Spec-Driven API Development.**

<Link className="button button--primary" to="/getting_started/cli_quick_start">Get started with Specmatic</Link>

## One specification, every stage of the API lifecycle

Design, build, test and govern high-quality, AI-ready APIs at scale. Drive every stage of the API lifecycle from the same API specifications, turning **OpenAPI/Swagger, Arazzo, AsyncAPI, GraphQL, gRPC and WSDL** into executable contracts.

Agree on the desired behaviour in a specification. Use it to test your implementation and mock its dependencies while teams build independently. Verify changes locally and in CI so integration drift is caught and corrected before services come together.

[Learn how executable contracts work](/contract_driven_development) · [Explore supported specifications and protocols](/supported_protocols)

## Bring executable contracts into your development workflow

### Work locally and in CI

Run contract tests and start mock servers from the command line. Use the same specifications during development and in your CI pipeline to check every change against the agreed behaviour.

[CLI quick start](/getting_started/cli_quick_start) · [Contract testing](/contract_driven_development/contract_testing) · [Service virtualization](/contract_driven_development/service_virtualization) · [CI integration](/references/continuous_integration)

### Give AI coding agents contract feedback

Connect your coding agent to Specmatic through its MCP server to run contract tests, manage mocks and check backward compatibility from an agent session. Use that feedback to correct implementation drift against the specification.

[Set up Specmatic MCP](/features/specmatic_mcp)

### Verify your MCP servers

Check MCP servers against their declared input and output schemas to catch mismatches that can break agent integrations.
