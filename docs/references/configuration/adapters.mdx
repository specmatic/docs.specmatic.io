# Adapters

## What are Adapters?

Adapters let you perform custom modifications to a request or response during execution.

An adapter takes the form of a command that can be configured to run at specific stages.

## How Adapters Work

As an example, in the above snippet, `pre_specmatic_request_processor` is an adapter name.
Specmatic executes the configured command and passes request data through STDIN.

Sample input to the adapter (STDIN):

```json
{
  "http-request": {
    "method": "POST",
    "path": "/api/data",
    "headers": {
      "Content-Type": "application/json"
    },
    "body": {
      "data": "eyJrZXkiOiAidmFsdWUifQ=="
    }
  }
}
```

Sample output from the adapter (STDOUT):

```json
{
  "http-request": {
    "method": "POST",
    "path": "/api/data",
    "headers": {
      "Content-Type": "application/json"
    },
    "body": {
      "data": {
        "key": "value"
      }
    }
  }
}
```

Read more about adapters [here](/features/adapters/request_response_adapters).

Note: Specmatic also supports specification adaptors via Overlays. Read more about [Specmatic's support for Overlays here](/features/overlays).
