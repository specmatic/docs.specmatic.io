# Environments

## Declare Environment Configuration

<Tabs groupId="environment_configuration">

  <TabItem value="specmatic-yaml" label="specmatic.yaml">

```yaml
version: 2
environments:
  staging:
    baseurls:
      auth.spec: http://localhost:8080
    variables:
      username: jackie
      password: PaSsWoRd
```

  </TabItem>

  <TabItem value="specmatic-json" label="specmatic.json">

```json
{
  "version": 2,
  "environments": {
    "staging": {
      "baseurls": {
        "auth.spec": "http://localhost:8080"
      },
      "variables": {
        "username": "jackie",
        "password": "PaSsWoRd"
      }
    }
  }
}
```

  </TabItem>

</Tabs>

The environments key in this example contains configuration for the `staging` environment. It can contain configuration for any number of environments.

## Environment Configuration Options

Each environment configuration can contain:

### Base URLs

`baseurls` - needed when running contracts as test as part of [authentication](/features/authentication)

### Variables

`variables` - these values are plugged into the Examples rows of an auth contract for [authentication](/features/authentication), or even when running regular contract tests
