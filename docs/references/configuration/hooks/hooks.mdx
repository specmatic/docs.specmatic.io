# Hooks

## What are Hooks?

A hook is simply a command that, which can be configured to run at specific stages of the contract testing process.
Hooks allow you to perform custom actions, such as modifying the contract before it is loaded, or processing test
results after execution.

## How Hooks Work

In the above snippet, `stub_load_contract` is the hook name. `python load.py` is executed, while the path of the original contract file is present in `CONTRACT_FILE` environment variable.

The command can parse the contract file and write it to standard out. Specmatic will read it as the new contract.

## Supported Hook Names

- `stub_load_contract`
- `test_load_contract`
